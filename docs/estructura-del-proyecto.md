# Estructura del Proyecto

## Organización General

El proyecto está dividido en tres grandes componentes:

- backend
- frontend
- docs

---

# Backend

El backend concentra toda la lógica del sistema.

Principales módulos:

- api
- core
- models
- prompts
- rag
- schemas
- services
- utils

---

# Frontend

El frontend implementa la interfaz gráfica.

Contendrá:

- páginas
- componentes
- estilos
- scripts
- recursos estáticos

---

# Docs

Contiene toda la documentación técnica del proyecto.

Su propósito es documentar las decisiones de arquitectura, facilitar el mantenimiento y servir como contexto para futuras implementaciones asistidas por IA.

---

# Recursos

La carpeta resources almacenará imágenes, documentos de ejemplo y demás recursos necesarios para la documentación del proyecto.
